# AnyWent

> "I can go somewhere in Europe next weekend — where should I go, and what should I do when I get there?"

A personal culture aggregator and trip-planning web app. Pulls event data from clubs, concert venues, museums and galleries across European cities and surfaces personalised, ranked bundles by city and weekend.

**anywent.com** — work in progress.
